# Final Project - Emotion Detector

## Project Name

Emotion Detector

## Description

This project is an AI-based web application for detecting emotions in text using the Watson NLP library.

The application analyzes text and identifies the following emotions:

- anger
- disgust
- fear
- joy
- sadness

It also identifies the dominant emotion based on the highest emotion score.

## Technologies Used

- Python
- Watson NLP
- Flask
- Requests
- Unit Testing
- Pylint

## Features

- Emotion detection from text
- Detection of five emotions
- Identification of the dominant emotion
- Flask web application
- Error handling for blank input
- Unit testing
- Static code analysis
